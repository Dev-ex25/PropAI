# PropAI Security Specifications & Test Plan

## 1. Data Invariants
1. **Private Identity**: Realtors can only create/update/read their own users profile, where `id` matches `request.auth.uid`.
2. **Lead Ownership Isolation**: Realtors can only access or modify leads where `assigned_user_id` is their own `uid`.
3. **Task Isolation**: A Task can only be managed (created, modified, or checked off) by the realtor assigned (`assigned_user_id == request.auth.uid`).
4. **Subscription Security**: Subscriptions entries can only be accessed or generated by the owner of the subscription (`user_id == request.auth.uid`).
5. **Property Listing Ownership**: Realtors can only create, update, or delete physical listings where `realtor_id == request.auth.uid`.
6. **Temporal Timestamps**: All server timestamps (like `created_at`) must be equal to `request.time` during creation.
